# AI 幼儿启蒙 L1 React 前端设计

## 目标

构建一个 4–6 岁幼儿英语启蒙横屏学习端的 L1 可交互打样 Demo，真实使用需求文档内嵌图片，并为视频、音频和后续后端接口保留稳定的资源边界。

## 架构

- React + JavaScript + Vite。
- React Router 负责六大模块和游戏子页面路由。
- Zustand 负责课程进度、解锁、积分兑换、答题结果等跨页状态；本地存储用于刷新后保留 Demo 状态。
- 领域数据集中在 `src/data`，媒体路径集中在 `src/assets`/`public/assets`，页面只消费类型化数据。
- 16:9 横屏 Shell 统一提供顶部导航、页面标题和内容区；窄屏给出横屏提示。

## 页面范围

今日学习、复习乐园、词句宝库（课课清/拼写大师/滚动复习/词汇大闯关）、拓展学习（课程目录/绘本/趣味口语）、反馈报告、积分商城。

## 素材

从 `AI 幼儿启蒙产品（4-6） - 打样demo.docx` 提取 56 张内嵌图片；未提供的视频和音频由类型化清单映射到 `public/media`，缺失时显示“素材待接入”状态，不阻断页面浏览。

## 验收

- 能启动开发服务器并完成生产构建。
- 六大模块可导航，核心解锁与积分兑换状态联动。
- 复习乐园、拼写大师、词汇大闯关可完成一轮并产出报告数据。
- 关键状态逻辑有单元测试，TypeScript 无错误。
