# 复习乐园优化设计

## 目标

将 L1 复习乐园完善为可重复完成的 8 题听辨游戏，满足原始 Demo 对解锁、音频、答题反馈、结算和报告数据联动的要求。

## 范围

- 保留当前横屏舞台和文档导出的背景、题图、水果、切开及庆祝素材。
- 页面进入后自动播放当前英文题干；提供明确可点的重播按钮和播放状态。
- 每题显示题号、题干、题图、yes/no 水果和进度。作答后本题锁定。
- 正确时仅对被选择水果展示切开动效和正确反馈；错误时仅抖动被选择水果并播放错误反馈。反馈后显示下一题操作。
- 完成第 8 题后显示彩带庆祝、正确题数、正确率、积分、重玩入口和词句宝库入口。
- 未看完课程视频时页面保持锁定并引导到今日学习；已完成视频或已完成复习时均可重复游玩，最近一轮成绩写入全局状态供报告消费。
- 修复复习乐园界面的乱码中文文案。

## 数据与素材

题库固定为 L1 文档定义的 8 道 yes/no 题：

1. `This is a lemon.` — yes
2. `I can see some oranges.` — no
3. `This is a mango.` — yes
4. `This is a cherry.` — no
5. `This is a banana.` — no
6. `This is a melon.` — yes
7. `This isn't a strawberry.` — no
8. `There are some mangoes.` — yes

题目图片沿用 `src/data/lesson.js` 映射的文档导出素材；每题补充对应题干音频资源映射。媒体尚未接入时，播放控件必须保持可用且给出不阻断游戏的提示。正确、错误和庆祝音效使用统一的音效触发接口，浏览器不允许自动播放时静默降级。

## 组件边界

- `src/data/lesson.js`：题目、图片和音频元数据的单一来源。
- `src/features/review/reviewLogic.js`：纯函数，计算进度、答案结果、百分比和结算数据。
- `src/features/review/ReviewPage.jsx`：管理题目状态、可访问按钮、媒体触发和页面切换。
- `src/features/review/review.css`、`review-layout.css`、`review-position.css`：保持各自职责，清理覆盖式重复规则，仅包含对应的视觉、布局或定位样式。
- `src/features/review/reviewLogic.test.js`：覆盖计分和结算边界；新增的纯逻辑须先写失败测试。

## 交互状态

`locked`（未完成视频）→ `question`（未选择）→ `answered`（展示正确或错误反馈）→ `question`（下一题）→ `summary`（8 题完成）。重玩将状态恢复至第一题，不改变视频解锁状态；每次结算都以本轮正确数更新报告使用的分数。

## 错误处理与可访问性

- 音频缺失、加载失败或浏览器拦截自动播放时，游戏仍可正常作答，重播控件显示简洁提示。
- 所有图片有语义化替代文本，纯装饰素材标记为隐藏；yes/no 按钮保留明确的可访问名称和禁用状态。
- 选择答案后只显示当前题对应反馈，避免其它水果同时出现动画。

## 验收

- 8 题答案、题图和进度与需求文档一致。
- 视频未完成时不可作答；完成后能进入、重玩并将最新得分同步至报告。
- 进入与手动重播均会尝试播放题干；音频失败不阻断流程。
- 正误和结算反馈准确且使用现有素材。
- 复习乐园不含乱码中文，逻辑单元测试、现有测试和生产构建通过。
