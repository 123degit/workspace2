# 词句宝库拼写与滚动复习移动端设计

## 目标

在 `354 × 844` 的安卓手机视口中，让拼写大师和滚动复习页面完整显示在一屏内，页面本身不出现纵向滚动；保留当前学习数据、发音、拼写得分和进入页面的导航路径。

## 范围

- 仅对 `max-width:480px` 生效。
- 桌面与平板的现有页面布局保持不变。
- 不修改词库数据、计分规则、路由和第三方依赖。

## 拼写大师

- 页面标题和主导航保持紧凑显示。
- 学习图片与播放发音入口放在上方小区域。
- 叶片字母使用紧凑 `2 × 3` 网格，答案槽固定在页面下方，所有可用字母和槽位无需页面滚动即可访问。
- 保留桌面端拖拽；手机端增加点按流程：点击一个叶片字母后，再点击一个空答案槽完成放置。错误放置继续播放现有失败音效，完成时保持现有加分、成功音效与自动下一词逻辑。
- 重置和下一词按钮在一屏内可见；成功消息不覆盖主要操作区。

## 滚动复习

- 保留全部 20 个复习词，不分页、不隐藏。
- 将词卡排列为 `4 × 5` 紧凑网格，每张词卡以适合触屏的最小尺寸显示英文词。
- 点击词卡播放该词对应的现有音频；没有匹配音频的词卡保持可查看但不抛出错误。
- 网格高度和字号随动态视口压缩，页面不产生纵向或横向溢出。

## 验收

- `354 × 844` 下，两个页面均满足 `scrollHeight <= clientHeight` 与 `scrollWidth <= clientWidth`。
- 拼写页可通过手机点按完成一个字母放置；桌面拖拽仍可用。
- 滚动复习同时展示 20 个词卡，点击可发音的词卡能调用对应音频。
- 新增样式和交互契约测试，并运行 `pnpm test --run`、`pnpm build` 与 `git diff --check`。
