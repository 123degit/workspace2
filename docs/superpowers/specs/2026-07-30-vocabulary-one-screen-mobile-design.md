# 词句宝库移动端一屏学习卡设计

## 目标

在 `354 × 844` 的安卓手机视口中，词句宝库的课程浏览页完整显示为一屏，不出现浏览器页面纵向滚动；保留词条学习、发音、前后切换和进入拼写挑战的功能。桌面端与平板端现有布局保持不变。

## 适用范围

- 仅对词句宝库课程浏览页的小屏布局生效，断点为 `max-width: 480px`。
- 拼写大师、词汇大闯关与滚动复习维持现有页面及交互，不改业务数据和学习进度逻辑。
- 不新增依赖，不修改路由或全局导航。

## 页面结构

手机端课程浏览页由以下区域组成，从上到下占满动态视口高度：

1. 精简的页面标题区，仅保留“词句宝库”和当前模式标题；隐藏四项学习统计，避免占用垂直空间。
2. 紧凑的模式导航与词条选择条。模式按钮保持可触达；词条列表改为单行横向滚动按钮，当前词条清晰高亮。
3. 主学习卡，占据剩余空间并包含当前单词、播放发音按钮、音标、中文释义、字母拼写、例句、配图、星级展示和上一词/下一词按钮。
4. 挑战入口保留在学习卡内或紧邻学习卡底部，点击后进入既有的词汇大闯关页面。

## 布局与视觉规则

- 使用 `100dvh` 作为小屏课程浏览页的可用高度；页面容器及其上级不产生纵向滚动，卡片内容在该高度内自适应压缩。
- 词条选择条允许横向滚动，但禁止横向页面溢出。
- 学习卡采用单列紧凑排版：文字信息在上，配图缩小并限制高度；长单词或例句可换行但不得推出视口。
- 前后切换按钮始终可见且不遮挡主要文字或配图。
- 控件的最小可点击尺寸保持适合触屏操作，选中词条和挑战入口保持明确视觉反馈。
- `481px` 及以上继续采用既有响应式规则，桌面端不受本次改造影响。

## 交互和状态

- 词条选择、上一词/下一词使用现有 `selected` 状态，并循环切换 `lessonWords`。
- 发音按钮继续调用 `playLessonAudio(current.audio)`。
- 挑战入口继续调用已有 `onChallenge` 回调，进入既有 `match` 标签页。
- 不改变词库数据、积分、音频资源或游戏计分行为。

## 边界与失败处理

- 若单词、音标或例句较长，使用现有文本换行能力和受限字号，不能造成页面横向滚动。
- 无法加载图片时保留 `alt` 文本；不影响词条切换、发音和挑战入口。
- 动态浏览器工具栏变化时由 `dvh` 重新计算可用高度，仍优先保持整页无纵向滚动。

## 验收与测试

- 增加样式契约测试，检查 `max-width: 480px` 的一屏容器、隐藏统计、横向词条条和紧凑学习卡规则。
- 在 `354 × 844` 浏览器视口验证 `document.documentElement.scrollHeight <= document.documentElement.clientHeight`，且不存在横向溢出。
- 手工验证词条按钮、上一词/下一词、发音按钮和挑战入口均可点击。
- 运行 `pnpm test --run`、`pnpm build` 与 `git diff --check`。
