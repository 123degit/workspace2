# 拼写大师素材配置设计

## 目标

保留词句宝库现有的荷叶拼写互动界面，将拼写大师配置为截图指定的五个水果词，并为每题接入对应的图片与拼读音频。

## 关卡内容

拼写题目固定按以下顺序展示：

1. `cherry`：`ch-e-rr-y`
2. `lemon`：`l-e-m-o-n`
3. `mango`：`m-a-n-g-o`
4. `melon`：`m-e-l-o-n`
5. `strawberry`：`s-tr-aw-b-e-rr-y`

每题沿用现有图片资源 `/assets/docx/image1.jpeg` 至 `/assets/docx/image5.png`，并使用 `/music/<单词>拼读音频.mp3` 作为拼读音频。

## 交互

- 保留现有点击荷叶字母块、重置、检查答案、下一词的流程。
- 点击单词图片或音频按钮时，播放当前题目的拼读音频。
- 不修改荷叶托盘的 CSS 伪元素；额外的空白荷叶继续作为视觉装饰。

## 数据与实现边界

- 继续以 `src/data/lesson.js` 的 `words` 作为拼写大师唯一题目来源。
- 为每个词条增加音频路径字段，组件不再硬编码单词、分块或资源路径。
- 不新增自动化测试；仅进行现有测试和生产构建验证。
