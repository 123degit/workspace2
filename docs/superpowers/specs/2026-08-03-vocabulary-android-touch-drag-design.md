# Android 拼写触摸拖拽设计

## 背景

拼写大师仅使用 HTML5 的拖放事件。安卓触摸环境通常不会产生可用的 `dragstart` 与 `drop` 事件，导致游戏无法互动。

## 目标

让安卓端保持与网页端相同的操作：按住字母荷叶、拖动到对应拼写槽、松手后完成放置。

## 范围

- 为拼写字母和拼写槽增加 Pointer Events 触摸拖拽路径。
- 保留现有桌面 HTML5 拖拽路径与成功、失败、计分逻辑。
- 不改动游戏关卡、资源、路由或一屏场景布局。

## 方案

1. 手指按下未放置字母时，记录被拖拽字母的索引和指针坐标，并创建一个随指针移动的视觉副本。
2. 指针移动时更新视觉副本位置，阻止浏览器将手势解释为滚动。
3. 指针松开时，使用 `document.elementFromPoint()` 查找目标拼写槽；命中后复用现有顺序校验、音效、计分和完成逻辑。
4. 鼠标仍走现有 HTML5 拖拽；触摸拖拽只在触摸型 Pointer Event 上启用。

## 验收标准

- 安卓触摸屏可长按并拖动任意未放置字母，视觉副本随手指移动。
- 拖到正确拼写槽松手后完成放置；拖错槽位触发既有失败反馈。
- 桌面鼠标拖拽保持可用。
- 游戏完成后仍触发既有成功反馈、计分与自动下一词。
