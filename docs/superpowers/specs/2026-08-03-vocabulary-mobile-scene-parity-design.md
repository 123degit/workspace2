# Android 拼写场景一致性设计

## 背景

当前安卓窄屏拼写页将原有的场景式游戏改为普通三段网格：单词卡移动到顶部中间，底部荷叶字母区不完整，视觉结构与桌面版不一致。

## 目标

在手机一屏内保留桌面场景的关键层级：右上角单词卡、中部拼写槽和底部完整荷叶字母区；仅缩小整体尺寸和安全边距。

## 范围

- 调整拼写游戏的移动端 CSS 布局与尺寸规则。
- 保持现有单词、拖拽/点击交互、音频和路由不变。
- 不开放页面纵向滚动，不影响大于 480px 的布局。

## 方案

1. 移除安卓端把场景元素改成静态网格流的覆盖规则。
2. 保留桌面版元素的绝对定位关系，并让场景容器以可用宽高为边界。
3. 使用基于容器宽高的 `clamp()` 尺寸与短屏高度媒体查询，缩小但不隐藏右上单词卡、拼写槽和荷叶字母。
4. 背景图使用完整场景比例，防止池塘和底部荷叶被裁切。

## 验收标准

- 在 360px × 640px、390px × 844px 和 412px × 915px 下，首屏内可见右上单词卡、拼写槽及所有五个荷叶字母。
- 场景元素相对位置与桌面版一致：单词卡右上、拼写槽居中、荷叶字母位于底部。
- 页面维持一屏且无纵向滚动；拖拽和点击拼写仍可用。
