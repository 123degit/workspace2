# Android 拼写页一屏适配设计

## 背景

安卓窄屏设备上的词句宝库「拼写大师」页面在内容高度超过首屏时被裁切。页面在 `max-width: 480px` 下同时使用 `height: 100dvh` 和 `overflow: hidden`，因此不能通过页面滚动补足可见空间。

## 目标

在保留一屏操作和禁止页面纵向滚动的前提下，使拼写游戏的单词图片、可拖拽字母和底部拼写槽在常见安卓手机高度内完整可见、可操作。

## 范围

- 仅调整 `src/features/vocabulary/vocabulary.css` 中窄屏拼写游戏的布局规则。
- 保留现有桌面、平板和词句概览页面样式。
- 不改变游戏逻辑、路由、图片资源或拖拽交互。

## 方案

1. 保留 `.vocab-page--mobile-game` 的 `height: 100dvh` 和 `overflow: hidden`，维持页面一屏体验。
2. 将拼写游戏容器的可用空间明确分给三部分：顶部单词图、可伸缩的树叶字母区、固定高度的拼写槽。
3. 使用 `clamp()` 限制顶部单词图与树叶卡片的高度；字母区使用 `minmax(0, 1fr)` 吸收剩余空间，避免把底部拼写槽推出视口。
4. 在短高度设备上增加 `max-height` 媒体查询，进一步压缩顶部图片、树叶卡片和间距，不开放整页滚动。

## 验收标准

- 在 360px × 640px、390px × 844px 和 412px × 915px 视口下，拼写游戏页面不出现页面级纵向滚动。
- 单词图片、全部可拖拽字母和底部拼写槽均在首屏内可见。
- 拖拽字母与点击式交互保持可用。
- 其他词句宝库标签页和宽度大于 480px 的布局不发生回归。
