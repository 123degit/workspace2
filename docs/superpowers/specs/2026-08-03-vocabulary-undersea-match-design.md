# 海底货架词汇配对设计

## 目标

将“词汇大闯关”替换为参考图中的海底货架关卡：左侧单词胶囊可拖动，右侧橙色货架接受匹配；成功后将水果图放入对应货架。

## 范围

- 使用提供的海底场景、单词胶囊和货架素材。
- 沿用现有五个单词、图片、音效、计分及完成反馈。
- 支持桌面鼠标和安卓 Pointer Events 触摸拖拽。
- 关卡保持在一屏内，适配窄屏安卓。

## 布局

- 舞台背景使用海底货架场景素材。
- 左侧为五个纵向排列的单词胶囊；右侧为五个纵向货架。
- 货架在匹配成功后显示对应水果图并锁定。

## 验收

- 单词可拖入正确货架；拖错不会完成。
- 安卓端手指拖动可完成匹配。
- 全部完成后保持既有积分和成功消息。
- 桌面与安卓首屏内均能看到所有五个匹配目标。
